# mongodb-gridfs-example

Exemplo de aplicação em Java e Spring para demonstrar o uso de **GridFS** no MongoDB para armazenamento de arquivos binários grandes.

---

## Visão Geral

O objetivo deste projeto é ilustrar como utilizar o **GridFS** do MongoDB para armazenar e recuperar arquivos (por exemplo, imagens, PDFs, vídeos) que podem ultrapassar o limite de tamanho de documento BSON padrão (~16MB).  
O GridFS divide os arquivos grandes em **chunks** e mantém metadados, facilitando leitura, escrita e manipulação de arquivos diretamente no banco de dados.

---

## Tecnologias / Bibliotecas

- Java  
- Spring
- MongoDB
